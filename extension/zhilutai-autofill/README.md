# 职路台网申填写助手

这是一个 Chrome Manifest V3 扩展，用于把职路台本地画像填写到当前校招网页。

## 安装

1. 先启动职路台：运行项目根目录的 `打开职路台.cmd`。
2. Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择本目录：`extension/zhilutai-autofill`。

## 使用

打开招聘官网或公共招聘平台的网申页面，点击扩展图标，选择画像并点击“读取画像并填写”。扩展只填写空白字段，不会点击提交、不会处理验证码，也不会读取密码字段。

画像中的手机号、邮箱、身份证号、民族、籍贯、政治面貌、外语水平、留学生状态、健康状况、现居住地和经历信息保存在职路台本机 E 盘数据库中；扩展仅通过 `127.0.0.1:4177` 读取当前选择的画像。证件照片和证书附件仍需在网页中手动上传。
