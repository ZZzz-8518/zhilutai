# 职路台

职路台是一款面向中国校园招聘的本地求职信息工作台。目前主要服务 2027 届校招，也可以通过画像修改毕业年份。它把公开招聘线索、招聘原文、专业适配判断、截止日期、投递入口和公司资料整理在一个网页中。

> 当前是轻量版。检索结果可能不完整，专业匹配结论仅供初筛；投递前请以企业官方招聘页面和招聘公告原文为准。

## 主要功能

- 多人画像：分别保存专业、相近专业、技能、学校、意向行业和城市。
- 校招岗位采集：从公开搜索、高校就业网、公共招聘平台和配置的数据源发现 2027 届校招信息。
- 宽口径专业筛选：覆盖明确相关、相近相关、专业优先但不排他、专业不限和能力可迁移岗位。
- AI 初审与复核：同一个 AI 接口执行两轮独立整理，减少明显误判，不需要第二个 API Key。
- 截止日期与投递入口：过滤已截止岗位，按截止日期排序，优先展示官网网申入口，同时保留平台、邮箱等其他渠道。
- 公司资料：招聘信息与公司介绍、官方待遇、带来源链接的社交平台评价分开保存。
- 求职进度：手动记录未投递、已投递、笔试、面试、Offer 等状态。
- 本地缓存与定时采集：已收集内容进入本地数据库，服务运行时可按设定时间采集，减少重复调用 API。

## 运行要求

- Node.js 22.5 或更高版本
- Google Chrome 或 Chromium
- 一个兼容 OpenAI Chat Completions 格式的 API Key

默认接口为 DeepSeek：

- API 地址：`https://api.deepseek.com`
- 模型：`deepseek-v4-pro`

界面只保留一套 API 配置。可以更改地址和模型，以使用其他兼容服务。

## 安装与启动

下载项目后，在项目目录执行：

```powershell
npm install
npm start
```

浏览器打开 [http://127.0.0.1:4177](http://127.0.0.1:4177)，先创建画像，再到“采集设置”填写 API Key，最后点击“AI 搜岗位”。

Windows 用户也可以双击 `打开职路台.cmd`。如果电脑存在 E 盘，这个启动方式默认把数据库、缓存、日志和工具放在 `E:\JobFinderData`；否则使用系统本地应用数据目录。

Windows 启动器会自动继承系统代理设置。使用代理软件时，请保持系统代理已开启；否则浏览器可以访问但后台采集服务可能无法访问部分招聘网站。

需要指定目录时，在启动前设置：

```powershell
$env:JOB_FINDER_DATA_DIR = "E:\JobFinderData"
$env:JOB_FINDER_TOOLS_DIR = "E:\JobFinderData\tools"
npm start
```

Chrome 不在常见安装位置时，可以用 `CHROME_PATH` 指定浏览器程序路径。

## 使用顺序

1. 在“画像”中新增本人或朋友的专业、技能、学校和求职偏好。
2. 在“采集设置”中填写一个 API Key，并确认接口地址和模型。
3. 点击“AI 搜岗位”，或开启每天多次定时采集。
4. 查看岗位的招聘原文、报名口径、截止日期、公司资料和投递入口。
5. 投递后手动更新进度。工具不会读取企业网申系统，也不会自动认定为“已投递”。

## 数据来源与限制

程序使用公开搜索结果、企业招聘网站、公共就业平台和用户有权访问的学校就业网站。小红书、抖音、知乎、牛客、应届生等社交或经验平台仅用于补充线索和带原链接的评价；登录限制、反爬机制和内容删除都可能导致信息无法自动读取。

学校就业网站按画像中的学校和省份启用，避免把需要校内身份的入口错误推荐给其他用户。无法核实的公司待遇、往届案例或评价会留空，不应由 AI 猜测补齐。

## 数据与安全

- API Key、画像、岗位缓存和投递记录保存在本机 SQLite 数据库中，不会写入仓库。
- API Key 会发送到你在设置中填写的接口地址，用于整理和复核招聘信息。
- 不要把真实数据库、日志、简历或 `.env` 文件提交到 GitHub。
- 如果 API Key 曾在聊天、截图或公开页面中出现，请先到供应商后台作废并重新生成。

## 网申填写助手

项目内置 Chrome 扩展目录：`extension/zhilutai-autofill`。

1. 运行根目录的 `打开职路台.cmd`，确认网页可以打开。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择 `extension/zhilutai-autofill` 文件夹。
4. 在画像中填写手机号和邮箱。打开招聘网页后点击扩展图标，选择画像并点击“读取画像并填写”。

扩展只填写空白字段，不会点击最终提交，不会读取密码、不处理验证码，也不会绕过招聘网站登录。填写完成后请自行检查并提交。
